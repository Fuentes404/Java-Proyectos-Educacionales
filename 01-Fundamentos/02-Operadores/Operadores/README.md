# Operadores en Java

Ejercicio en Java que muestra el uso de los distintos tipos de operadores del lenguaje: aritméticos, de asignación, de incremento/decremento, relacionales y lógicos.

## 📋 Descripción

Este proyecto es un ejercicio introductorio en Java que cubre:

- Operaciones matemáticas básicas entre variables.
- Operadores que combinan una operación con la asignación de un valor.
- Incremento y decremento de una variable.
- Comparación de valores mediante operadores relacionales.
- Combinación de condiciones booleanas con operadores lógicos.

## 🧩 Operadores utilizados

| Tipo | Operadores | Descripción |
|---|---|---|
| Aritméticos | `+` `-` `*` `/` `%` | Realizan operaciones matemáticas entre dos valores |
| De asignación | `+=` `*=` | Combinan una operación con la asignación del resultado |
| Incremento/Decremento | `++` `--` | Aumentan o disminuyen en 1 el valor de una variable |
| Relacionales | `>` `==` | Comparan dos valores y devuelven un `boolean` |
| Lógicos | `&&` `\|\|` | Combinan condiciones booleanas |
