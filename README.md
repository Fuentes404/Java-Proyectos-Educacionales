# Java Proyectos Educacionales 

Repositorio con ejercicios y proyectos de Java desarrollados durante la universidad, organizados por tema. Cubre progresivamente desde fundamentos (variables, POO) hasta temas avanzados como colecciones, genéricos, programación funcional, concurrencia, patrones de diseño, persistencia con BD y proyectos integradores.

## 🗺️ Roadmap de temas

### 1. Fundamentos
- [x] Variables, tipos de datos primitivos y casting
- [x] Operadores (aritméticos, lógicos, relacionales, bit a bit)
- [x] Estructuras condicionales (if, switch, switch expressions)
- [x] Estructuras de repetición (for, while, do-while, for-each)
- [x] Arrays (unidimensionales y multidimensionales)
- [ ] Métodos (parámetros, retorno, sobrecarga - overloading)
- [ ] Scanner y entrada de datos por consola

### 2. Programación Orientada a Objetos (POO)
- [x] Clases y objetos
- [x] Atributos, constructores y this
- [X] Encapsulamiento (getters/setters, modificadores de acceso)
- [x] Herencia (extends, super)
- [x] Polimorfismo (sobreescritura)
- [x] Clases abstractas
- [x] Interfaces (métodos default y static)
- [x] Composición
- [ ] Enums
- [ ] Clases internas (inner classes, anonymous classes)

### 3. Manejo de errores
- [ ] Try-catch-finally
- [ ] Excepciones checked vs unchecked
- [ ] Excepciones personalizadas (extends Exception)
- [ ] Try-with-resources

### 4. Colecciones
- [ ] ArrayList / LinkedList
- [ ] HashSet / TreeSet / LinkedHashSet
- [ ] HashMap / TreeMap / LinkedHashMap
- [ ] Queue / Deque / Stack
- [ ] Iterator y for-each sobre colecciones
- [ ] Comparable vs Comparator
- [ ] Collections (métodos utilitarios)

### 5. Genéricos (Generics)
- [ ] Clases genéricas propias
- [ ] Métodos genéricos
- [ ] Wildcards (? extends, ? super)

### 6. Programación funcional
- [ ] Expresiones Lambda
- [ ] Interfaces funcionales (Function, Predicate, Supplier, Consumer)
- [ ] Streams (map, filter, reduce, collect, sorted)
- [ ] Optional
- [ ] Method references (::)

### 7. Entrada/Salida (I/O)
- [ ] Lectura/escritura de archivos de texto
- [ ] Serialización de objetos
- [ ] Manejo de rutas (Path, Files - NIO)

### 8. Concurrencia
- [ ] Thread y Runnable
- [ ] Synchronized
- [ ] ExecutorService
- [ ] CompletableFuture

### 9. Patrones de diseño
- [ ] Singleton
- [ ] Factory
- [ ] Observer
- [ ] Strategy
- [ ] Builder
- [ ] Decorator

### 10. Persistencia y bases de datos
- [ ] JDBC (conexión básica)
- [ ] CRUD desde consola conectado a BD
- [ ] JPA/Hibernate

### 11. Testing
- [ ] JUnit (pruebas unitarias básicas)
- [ ] Assertions

### 12. Proyectos integradores
- [ ] CRUD completo en consola
- [ ] Proyecto con Maven/Gradle
- [ ] API REST básica (Spring Boot)
- [ ] Proyecto con arquitectura en capas

## 🛠️ Tecnologías

- Java (JDK 21)

### Cómo clonar este repositorio

```bash
git clone https://github.com/tu-usuario/Java-Proyectos-Educacionales.git
cd Java-Proyectos-Educacionales
```

Luego puedes entrar a la carpeta del ejercicio que quieras revisar o compilar, por ejemplo:

```bash
cd 01-Fundamentos/001-variables-tipos-datos-casting
javac Main.java
java Main
```
